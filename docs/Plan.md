# STEMNIST 近传感神经形态分类研究计划

## 1. 研究目标

本项目面向由柔性压敏阵列、NbOx 阈值开关振荡神经元、突触晶体管、跨阻放大器（TIA）和后突触振荡神经元构成的近传感神经形态系统，研究其对连续触觉时序信息的编码与分类能力。

项目分为两个阶段：

1. **原始压力 SNN 基线**：将 STEMNIST 的连续压力帧直接作为 SNN 第一层神经元的输入电流，建立可复现的分类基线。
2. **神经形态系统编码**：将压力序列映射为时变输入电阻 \(R_{l,pre}(t)\)，经过“前振荡神经元—突触—TIA—后振荡神经元”编码后，再送入与基线同构的 SNN。

两条实验路径如下：

```text
路径 A：原始压力
240×16×16 压力序列
→ 训练集统计量归一化
→ 连续值直接注入 Conv-SNN
→ 35 类字符预测

路径 B：神经形态系统编码
240×16×16 压力序列
→ 压力/ADC 到 Rl,pre(t) 的映射
→ 256 路“前神经元—突触—TIA—后神经元”
→ 后神经元脉冲检测与时间分箱
→ 与路径 A 同构的 Conv-SNN
→ 35 类字符预测
```

两条路径采用相同的数据划分、网络拓扑、时间长度、损失函数和训练协议，但分别训练权重。这样既控制 SNN 分类器的结构变量，又允许网络适应两种不同的输入表示。

STEMNIST 原论文报告的 89.16% SNN 测试准确率使用的是经过差分阈值编码的双通道 ON/OFF 事件，而不是原始连续压力。因此，该结果只作为数据加载和论文模型复现的辅助参考，不作为路径 A 必须达到的准确率目标。

## 2. 数据准备与公平对照

### 2.1 数据集基本信息

STEMNIST 包含：

- 35 个类别：大写字母 A–Z 和数字 1–9；
- 7,700 个样本，每类 220 个；
- 34 名参与者；
- 每个样本持续 2 秒；
- 采样率 120 Hz；
- 每个样本 240 帧；
- 每帧包含 16×16 个 taxel；
- 原始单样本形状为 `[240, 16, 16]`。

数据来源：

- [STEMNIST Zenodo 数据集](https://zenodo.org/records/19469535)
- [STEMNIST 原始论文](https://arxiv.org/abs/2601.01658)

下载后应校验数据压缩包的 MD5：

```text
6ca4638b2f95bf34f59873ab62399bd8
```

原始数据和生成的训练缓存不纳入版本控制。

### 2.2 样本清单

数据准备阶段首先建立统一的样本清单。每条记录至少包含：

```text
sample_id
participant_id
label
label_index
repetition
raw_file_path
shape
dtype
minimum
maximum
```

标签索引固定为：

```text
A, B, ..., Z, 1, 2, ..., 9
```

即 A–Z 对应 0–25，数字 1–9 对应 26–34。标签顺序一经确定，所有实验、混淆矩阵和 checkpoint 均不得改变。

### 2.3 内部数据格式

数据加载器输出批次的内部格式为：

```text
[N, T, C, H, W]
```

其中：

```text
T = 240
C = 1
H = 16
W = 16
```

进入 SpikingJelly 多步网络前，仅执行一次维度转换：

```text
[N, T, C, H, W] → [T, N, C, H, W]
```

正式实验使用 240 个时间步，以保留原始 120 Hz 时序分辨率。20 时间步版本通过每 12 帧聚合为一个时间箱，用于：

- 开发阶段快速验证；
- 与原论文 20 时间步设置对照；
- 时间分辨率消融；
- 排查 240 步训练的性能和显存问题。

连续压力的时间聚合使用时间箱内均值；脉冲序列的时间聚合使用时间箱内事件计数。

### 2.4 归一化

> 修正：不进行归一化，以保证与第二阶段的可比较性

归一化参数只能由当前折或当前随机种子的训练集计算，禁止读取验证集和测试集统计量。

推荐的基线校正方式为：

1. 取所有训练样本前 12 帧；
2. 计算每个 taxel 的中位数基线 \(b_{xy}\)；
3. 对压力值执行：

\[
X(t,x,y)=\operatorname{clip}
\left(
\frac{P(t,x,y)-b_{xy}}{255-b_{xy}},
0,
1
\right)
\]

归一化参数随实验配置和数据划分一起保存。不得使用单个完整样本的最大值、最小值或未来帧统计量进行归一化，以避免非因果处理和测试信息泄漏。

### 2.5 数据划分

项目同时报告两套数据划分。

#### 样本级分层划分

> 修正：暂时只需要使用一个随机种子42即可

使用以下五个随机种子：

```text
42
```

每个种子执行：

1. 按类别分层划分 80% 训练数据和 20% 测试数据；
2. 从训练部分再次分层划出 20% 作为验证集；
3. 保存训练、验证和测试的 `sample_id`。

该结果用于与原论文实验条件进行近似对照，但同一参与者的不同样本可能同时出现在训练集和测试集中。

#### 参与者隔离划分

> 修正：不进行该参与者隔离划分

使用 5 折 `StratifiedGroupKFold`：

- `label` 用于维持类别分布；
- `participant_id` 作为 group；
- 同一参与者不得跨训练、验证和测试集合；
- 外层每折作为一次独立测试；
- 外层训练参与者中再按 group 划分验证集。

该实验用于评价模型对未知书写者的泛化能力。

所有输入路径必须读取完全相同的划分清单。不得为原始压力路径和神经形态编码路径重新随机划分数据。

## 3. SpikingJelly SNN 设计

### 3.1 网络结构

主实验采用单通道 Conv-SNN：

```text
输入：[T, N, 1, 16, 16]
→ Conv2d(1→8, kernel_size=4, stride=1, padding=0)
→ LIF
→ MaxPool2d(kernel_size=2)
→ Conv2d(8→16, kernel_size=3, stride=1, padding=1)
→ LIF
→ MaxPool2d(kernel_size=2)
→ Flatten：16×3×3 = 144
→ Dropout(0.3)
→ Linear(144→35)
→ 输出 LIF
→ 沿时间维累加输出脉冲
→ 35 类分类
```

参数量为：

```text
Conv1：8×(1×4×4+1)      = 136
Conv2：16×(8×3×3+1)     = 1,168
Linear：35×(144+1)      = 5,075
总计                         6,379
```

原论文 ON/OFF 事件复现使用双通道输入，参数量为 6,507。它作为辅助复现实验，不属于两条主路径的公平对照网络。

### 3.2 SpikingJelly 配置

统一使用：

```text
spikingjelly.activation_based
```

LIF 神经元的基准设置为：

```text
tau = 10
decay_input = False
surrogate_function = ATan
step_mode = "m"
```

其中 `tau=10`、`decay_input=False` 对应约 0.9 的膜电位保持系数。模型建立后统一切换到多步模式，使网络直接处理 `[T,N,C,H,W]` 张量。

每个 batch 完成前向、损失计算和反向传播后，必须调用：

```text
functional.reset_net(model)
```

以清除 LIF 膜电位和其他有状态模块，防止不同样本或 batch 之间发生状态串扰。验证和测试循环同样必须正确复位。

SpikingJelly 多步模式、计算后端和状态复位以其[官方 functional 接口](https://spikingjelly.readthedocs.io/zh-cn/latest/APIs/spikingjelly.activation_based.functional.html)为准。

### 3.3 训练配置

主实验固定使用：

| 项目 | 配置 |
|---|---:|
| 优化器 | Adam |
| 初始学习率 | 0.005 |
| 权重衰减 | \(10^{-4}\) |
| Batch size | 64 |
| Epoch | 50 |
| Dropout | 0.3 |
| 代理梯度 | ATan |
| 输出 | 时间维输出脉冲计数 |
| 模型选择 | 验证集 macro-F1 最优 |

每次训练必须保存：

- 完整实验配置；
- 数据划分标识；
- 随机种子；
- 最佳和最后一个 checkpoint；
- 每个 epoch 的训练/验证损失；
- Accuracy 和 macro-F1；
- 各层平均发放率；
- 运行环境和 GPU 信息；
- 峰值显存、吞吐率和训练时间。

测试集只在模型与超参数锁定后评估。

### 4.1 版本策略

优先锁定：

```text
spikingjelly==2.0.0.dev0
```

若该版本在远程环境中无法通过最小前向、反向或后端兼容性测试，则自动回退到：

```text
spikingjelly==0.0.0.0.14
CuPy 后端
```

无论使用哪个版本，都必须锁定确切依赖版本，禁止正式实验直接依赖未固定提交的 `master` 分支。

版本信息参考：

- [SpikingJelly PyPI](https://pypi.org/project/spikingjelly/)
- [SpikingJelly 官方项目](https://github.com/fangwei123456/spikingjelly)

### 4.2 多步并行

正式训练必须采用 `step_mode="m"` 多步并行，直接处理 20 或 240 个时间步。不得在 Python 层使用循环逐帧调用单步网络，因为这会显著增加调度开销并降低 GPU 利用率。

输入在加载阶段保持 `[N,T,C,H,W]`，进入模型前一次性转换为 `[T,N,C,H,W]`，避免在网络各层重复变换。

### 4.3 后端选择

在远程 GPU 上依次测试：

1. Triton；
2. CuPy；
3. PyTorch。

每种后端使用相同输入、权重和随机种子，执行：

- 多步前向；
- 损失计算；
- 反向传播；
- 梯度对比；
- 峰值显存统计；
- 预热后的吞吐率测试。

只有输出、损失和梯度与 FP32 参考结果在既定数值容差内一致的后端才可进入性能比较。最终选择通过正确性测试且吞吐率最高的后端，并在所有正式对照实验中保持不变。

### 4.4 混合精度

精度策略为：

1. GPU 支持时优先使用 BF16；
2. 否则使用 FP16 和梯度缩放；
3. 损失、指标、脉冲总数和混淆矩阵在 FP32 或更高精度下累计；
4. 保留一套 FP32 小规模参考结果，用于验证混合精度没有造成异常偏差。

固定输入尺寸时可启用：

```text
cuDNN benchmark
TF32
```

所有性能相关开关必须写入运行配置和结果记录。

### 4.5 数据输入优化

7,700 个样本的原始 `uint8` 压力张量约占 0.5 GB。数据准备阶段将分散的 HDF5 文件预打包为连续张量缓存，避免每个 epoch 重复打开大量小文件。

首选路径为：

1. 将完整 `uint8` 数据缓存预载入 GPU；
2. 使用索引张量选取 batch；
3. 在 GPU 上转换浮点类型；
4. 在 GPU 上执行训练集基线校正、归一化和时间分箱。

若显存不足，则回退到：

- pinned host memory；
- `non_blocking` 异步传输；
- persistent DataLoader workers；
- 合理的 `prefetch_factor`；
- 计算与数据传输重叠。

### 4.6 Batch 和并发策略

正式对照实验的 batch size 保持为 64，以避免为了提高硬件利用率而改变优化条件。

若单个训练任务无法充分利用 GPU，则优先并发运行不同的随机种子或交叉验证折次。并发任务数量通过启动前的显存和吞吐率测试决定，并为峰值显存保留安全余量。

不得仅为了提高 GPU 利用率而在某条输入路径上单独增大 batch size。若未来确需修改 batch size，必须作为统一超参数实验同时应用于两条路径。

### 4.7 显存优化

默认不启用梯度检查点和脉冲压缩，因为它们通常以额外计算换取显存。

只有在 240 时间步反向传播无法满足目标 batch size 时，才启用 SpikingJelly 的显存优化功能，并重新测试：

- 数值一致性；
- 峰值显存；
- 单 epoch 时间；
- 总训练时间。

### 4.8 运行模式

提供两种运行模式：

#### 快速模式

- 多步 GPU 后端；
- BF16 或 FP16；
- cuDNN benchmark；
- TF32；
- 多个种子或折次并发；
- 用于正式多次实验。

#### 可复现模式

- 固定所有随机种子；
- 启用可用的确定性设置；
- 关闭会造成不可控差异的性能选项；
- 用于复核关键结果，而不是执行全部超参数和多折实验。

## 6. 第二阶段：神经形态系统接入

### 6.1 电路输入方式

保留现有 LTspice 文件作为只读基准，另建实验变体。

前振荡神经元采用：

```text
Vin = 2.3 V
```

将 U1 内部固定的：

```text
Rload = 10 kΩ
```

改为可随时间变化的：

\[
R_{l,pre}(t)
\]

每个样本包含：

- 100 ms 无压力预热；
- 2 秒压力输入；
- 预热数据不送入 SNN；
- 样本结束后器件状态复位。

### 6.2 压力—电阻映射

正式映射需要两部分标定：

1. STEMNIST ADC 值到实际压力；
2. 实际压力到实验压敏电阻 \(R_{l,pre}\)。

标定数据至少包含：

```text
pressure
resistance_ohm
measurement_id
measurement_uncertainty
```

建议对 \(\log R\) 进行单调插值，并记录输入超出标定范围时的截断比例。

当前尚无压力—电阻标定数据，因此第二阶段可以先完成：

- 映射接口；
- 合成单调曲线；
- 参数敏感性分析；
- 电路变体和代理模型验证流程。

占位映射得到的分类结果不得作为论文正式定量结论。若最终只有归一化压力映射，必须明确表述为“相对压力映射”，并报告不同电阻范围下的敏感性。

### 6.3 256 路空间编码

16×16 阵列的每个 taxel 对应一条参数相同、状态独立的神经形态编码通道：

```text
Rl,pre(t)
→ 前振荡神经元
→ 突触晶体管
→ TIA
→ 电平移位
→ 后振荡神经元
→ final_out
```

后神经元的 `final_out` 通过上升沿检测得到脉冲事件，并以 8.33 ms 为时间箱进行计数，形成：

```text
[240, 1, 16, 16]
```

该张量与路径 A 使用相同的空间尺寸、通道数和时间步数，可直接送入同构 Conv-SNN。

### 6.4 LTspice 与快速代理模型

> 这里需要再进行思考一下

**不能对全部 `7,700×256` 条 taxel 序列逐一运行完整 LTspice。**完整数据集编码采用保留内部动态状态的快速代理模型，LTspice用于：

- 电阻恒值实验；
- 电阻阶跃实验；
- 电阻斜坡实验；
- 代表性 STEMNIST 压力轨迹；
- 代理模型独立验证。

代理模型需要保留：

- 前振荡神经元状态；
- 突触慢、快和中等时间尺度状态；
- TIA/滤波状态；
- 后振荡神经元状态。

代理模型进入全数据集编码前必须达到：

- 输出脉冲数相对误差不超过 5%；
- 中位脉冲时间误差不超过一个 8.33 ms 时间箱；
- 在独立验证序列上不存在系统性的漏脉冲或伪脉冲。

若不满足标准，则继续修正代理模型，不能直接进入正式分类。

- 每类达到稳定预测所需的时间；
- 正确预测随时间的置信度变化。

### 7.3 稀疏性和计算指标

- 输入非零比例；
- 每个样本的输入事件数；
- 每层神经元发放率；
- 每个样本的总内部脉冲数；
- 密集输入的乘加操作估算；
- 稀疏事件输入的累加操作估算；
- 参数量和中间状态存储量。

这些指标属于解析估算，不等同于真实硬件功耗。

### 7.4 鲁棒性

对两条路径施加相同的原始输入扰动：

- 不同强度的 ADC 噪声；
- 随机 taxel 丢失；
- 连续区域 taxel 失效；
- 压力幅值缩放；
- 基线漂移；
- 时间采样抖动。

扰动必须在两种编码器之前施加，确保比较的是两条处理链对同一传感扰动的响应。

### 7.5 GPU 训练效率

记录：

- 每秒处理样本数；
- 每秒处理时间帧数；
- 单 epoch 时间；
- 总训练时间；
- GPU 平均利用率；
- 峰值显存；
- 不同后端和精度模式的加速比。

性能数据用于说明训练工程效率，不作为神经形态硬件能效结论。

## 8. 论文结论边界

不预设神经形态系统编码后一定获得更高准确率。

结论规则预先定义为：

- 准确率差的配对 95% 置信区间整体大于 0，才称为“准确率提升”；
- 准确率差置信区间下界高于 −2 个百分点，可称为“准确率基本保持”；
- 编码后事件占用率或估算操作量确实下降，才称为“稀疏化或计算量优势”；
- 正常时间顺序显著优于时间打乱或反转，才说明模型利用了时序信息；
- 早期输入即可达到较高准确率时，可讨论低延迟识别潜力；
- 没有真实器件功耗测量时，不宣称实际能耗降低；
- 使用归一化压力—电阻映射时，不将结果表述为绝对物理压力下的硬件性能。

如果系统编码后的准确率与原始压力基线相近，但输入明显更稀疏、早期识别更快或抗噪性更好，仍可构成近传感计算价值。
