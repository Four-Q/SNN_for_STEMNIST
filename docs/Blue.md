# STEMNIST 近传感神经形态计算研究蓝图

## 研究背景

柔性压力传感器能够持续记录接触位置、书写轨迹、压力变化和笔画顺序，因而产生具有空间与时间信息的连续触觉数据。传统处理方式通常需要先对这些模拟信号进行密集采样和传输，再由数字处理器完成特征提取与分类。随着传感阵列规模和采样频率提高，这种“先完整采集、再集中计算”的方式会带来较大的数据传输和计算负担。

本研究已经具备氧化铌阈值开关器件和突触晶体管器件，并以阈值开关器件构成了振荡神经元。在此基础上，通过前突触振荡神经元、动态突触、跨阻放大器和后突触振荡神经元，可以构成一条连续传感信号到脉冲输出的神经形态处理链。该系统有望在靠近传感器的位置完成时序编码，将密集连续压力变化转化为更适合脉冲神经网络处理的事件表示。

STEMNIST 数据集由 16×16 柔性压敏阵列采集，记录了字符书写过程中连续变化的压力分布，既包含字符的空间形状，也包含笔画顺序、书写速度、停顿和压力变化。因此，它适合作为验证该神经形态系统时空编码能力的应用任务。

## 核心研究问题

本研究希望回答：

> 由振荡神经元、动态突触和模拟接口组成的神经形态系统，能否在保留 STEMNIST 字符时空信息和分类能力的同时，将密集连续压力序列转化为更稀疏、更适合 SNN 处理的脉冲表示？

该问题不应只通过最终分类准确率判断。系统的价值还可能体现在：

- 对真实时间顺序的利用；
- 较早时间内完成有效识别；
- 输入事件和内部脉冲更加稀疏；
- 估算计算操作量降低；
- 对噪声、漂移和传感单元失效更稳健；
- 对未知参与者书写方式具有更好的泛化能力。

## 总体研究路线

研究分为两个阶段。

### 第一阶段：建立原始压力 SNN 基线

首先将 STEMNIST 的连续压力帧直接输入 SpikingJelly 构建的卷积脉冲神经网络。每个时间步的 16×16 压力帧作为网络第一层脉冲神经元的连续输入电流，从而尽可能保留原始压力幅值和 120 Hz 时间结构。

该阶段用于：

- 验证原始连续压力是否能够被 SNN 有效分类；
- 建立后续硬件编码路径的公平对照；
- 确定网络结构、数据划分和评价协议；
- 分析时间顺序和时间分辨率对分类的贡献。

### 第二阶段：加入神经形态系统编码

将每个 taxel 的连续压力变化映射为前振荡神经元的时变输入电阻 \(R_{l,pre}(t)\)。16×16 阵列在概念上对应 256 条参数相同、状态独立的神经形态编码通道：

```text
压力
→ 时变输入电阻
→ 前突触振荡神经元
→ 动态突触晶体管
→ TIA 与模拟接口
→ 后突触振荡神经元
→ 输出脉冲
```

各通道的后神经元脉冲按统一时间窗口组织为空间脉冲序列，再输入与第一阶段同构的 SNN。

完整数据集不直接进行数百万次 LTspice 仿真。LTspice主要用于验证电路行为和校准快速动态模型，经过验证的快速模型再负责批量编码 STEMNIST 数据。

## 公平对照原则

原始压力路径和神经形态系统编码路径应遵循以下原则：

- 使用完全相同的训练、验证和测试样本；
- 使用相同的 SNN 拓扑和参数规模；
- 使用相同的时间长度和训练协议；
- 两种输入表示分别训练权重；
- 同时报告样本级随机划分和参与者隔离划分；
- 不根据测试集结果反向调整编码和训练参数。

原论文基于 ON/OFF 差分事件的 SNN 结果可作为辅助复现参考，但不能代替原始连续压力直接输入的主基线。

## 评价方法

### 分类能力

比较两条路径的整体准确率、宏平均 F1、各类别识别能力和混淆关系，并通过多个随机种子和参与者隔离实验评价结果稳定性。

### 时间信息

通过时间顺序打乱、时间反转、不同时间分辨率和不同输入时长实验，判断模型是否真正利用书写过程中的笔画顺序和动态变化，而不是只依赖最终累积的字符形状。

### 早期识别

分别使用字符书写开始后的部分时间序列进行预测，观察系统能否在完整 2 秒输入结束前形成可靠分类结果，以评价低延迟识别潜力。

### 稀疏性与计算量

统计神经形态编码后的事件数量、输入非零比例、网络内部发放率和估算操作量，并与连续压力直接输入路径比较。

### 鲁棒性

在原始压力端加入相同的噪声、基线漂移、压力幅值变化和 taxel 失效，再分别通过两条路径处理，以评价神经形态编码是否对真实传感扰动具有缓冲作用。

### 用户泛化

除普通随机划分外，使用参与者完全隔离的测试方式，评价系统面对未参与训练的新书写者时的识别能力。

## 预期贡献

本研究预期形成以下贡献：

1. 建立 STEMNIST 连续触觉数据与器件级神经形态系统之间的映射方法。
2. 展示柔性压力感知、振荡神经元、动态突触、模拟接口和 SNN 组成的完整近传感计算链路。
3. 在相同分类网络下，对原始压力输入和神经形态编码输入进行公平比较。
4. 从分类性能、时间信息、早期识别、稀疏性和鲁棒性等多个角度评价硬件编码价值。
5. 为后续真实柔性神经形态系统集成、在线推理和实际能效测量提供方法基础。

## 结论边界

本研究不预设神经形态编码一定提高分类准确率。只有统计结果明确支持时，才能将其表述为准确率提升。

如果神经形态编码后的准确率与原始压力基线相近，但输入明显更稀疏、较早时间即可识别、对传感噪声更稳健或估算操作量更低，仍可构成近传感计算优势。

在没有真实硬件功耗测量的情况下，只能报告事件稀疏度、操作量和低功耗潜力，不能直接宣称实际能耗下降。在压力—电阻标定尚未完成时，占位映射只能用于方法和敏感性验证，不能作为绝对物理压力条件下的正式器件结论。
